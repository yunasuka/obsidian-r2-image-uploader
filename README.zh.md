# Cloudflare Image Uploader

[English](README.md)

把笔记里的网络图片存进你自己的 [Cloudflare R2](https://developers.cloudflare.com/r2/) 存储桶，链接换成你的，原网站删图也不受影响。粘贴、拖入的图片也直接上传。

## 功能

**网络图片**
- **自动转存**：新笔记出现（剪藏或从其他设备同步来）几秒后，转存其中的网络图片。默认关闭，按设备开启，一台常开的电脑打开即可。可限定文件夹。
- **粘贴网页内容后**转存。
- **命令**：转存当前笔记或所有笔记。下载不到的保留原链接，最后列出。
- **记录原网址**，「把当前笔记的图片换回原网络链接」可换回。
- 每个网站同时最多 2 个请求，被限流会等待。代码块里的链接不动。

**本地图片**
- **粘贴 / 拖入即上传。** 上传失败先存为附件，之后自动补传。
- **上传已有本地图片**（当前笔记或整个库），保留尺寸和说明文字（`![[a.png|300]]` → `![|300](https://…)`）。

**通用**
- 文件名为内容哈希（`{hash}.{ext}`），同一张图只存一份。
- 可选转 WebP，变小才用（GIF、SVG、动态 PNG 不转）。
- 不会删除 R2 里的任何图片。
- 支持电脑和手机，存储桶无需配置 CORS。

## 配置

1. Cloudflare 后台 → R2 → **创建存储桶**。
2. 存储桶 → 设置 → **自定义域**：绑定一个托管在 Cloudflare 的域名，如 `img.example.com`（`r2.dev` 有限速，仅供测试）。
3. R2 → **管理 API 令牌** → 创建帐户 API 令牌，权限「对象读和写」，只给这个存储桶。
4. Obsidian → 设置 → Cloudflare Image Uploader：填账户 ID、存储桶、两个密钥和公开访问地址，点「测试连接」。
5. 在「网络图片」里，在需要的设备上打开自动转存。

## 命令

整库的两个命令在设置页「工具」里也有。

| 命令 | 作用 |
|---|---|
| 把当前笔记的网络图片转存到 R2 | 转存当前笔记的网络图片并改写链接 |
| 把所有笔记的网络图片转存到 R2… | 对所有笔记执行，先显示数量 |
| 上传当前笔记里的本地图片 | 上传当前笔记的本地图片并改写嵌入 |
| 上传整个库的本地图片… | 对所有笔记执行，先显示数量 |
| 补传上传失败的图片 | 上传因失败而存在本地的图片 |
| 把当前笔记的图片换回原网络链接 | 换回图片原来的网址 |
| 停止正在进行的任务 | 处理完当前笔记后停止，再次运行可继续 |

失败两次的图片，自动转存会跳过（手动命令仍会尝试，设置里可清空记录）。限流和网络错误不计入。

上传后本地文件默认保留。「上传本地文件后」选「移到回收站」时，只有没有任何笔记或白板提到的文件才会删除。

## 文件名模板

默认 `{hash}.{ext}`。占位符：`{hash}`（SHA-256 前 16 位）、`{hash:N}`、`{ext}`、`{name}`、`{year}`、`{month}`、`{day}`、`{timestamp}`。斜杠表示文件夹：`notes/{year}/{month}/{hash}.{ext}`。

含 `{hash}` 时已存在的图不重复上传；不含时同名文件不覆盖，改为加时间戳。

## 隐私和安全

- 只连接你的 R2 接口、你的公开地址（测试连接时）和笔记里图片所在的网站。不收集数据。
- **上传的图片，有链接的人都能打开。** 存储桶无法被列出，哈希文件名无法猜到。
- 密钥存在每台设备的 Obsidian 密钥存储里。「密钥随库同步」会改为明文存进 `data.json`，仅在同步渠道私有时使用。令牌请只授权图床存储桶。
- 转存的图片仅供个人存档，请尊重原作者权利。

## 开发

```bash
npm install
npm run dev        # 监听构建
npm test           # 单元测试
npm run build      # 类型检查 + 生产构建
npm run install-vault -- /path/to/vault
```

`.env.local` 里有 `R2_ACCOUNT_ID`、`R2_BUCKET`、`R2_PUBLIC_URL`、`R2_ACCESS_KEY_ID`、`R2_SECRET_ACCESS_KEY` 时，`test/r2.e2e.test.ts` 会对真实存储桶测试。

发版：改 `manifest.json`、`package.json`、`versions.json` 的版本号，`npm run build`，然后：

```bash
gh release create 1.0.1 main.js manifest.json styles.css --title 1.0.1 --notes "..."
```
